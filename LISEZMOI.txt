Easy Route ! — mise en ligne

1. Le site
   Easy Route est servi par GitHub Pages depuis la branche main, sous le domaine
   easyroute.cloud (fichier CNAME). Chaque fusion sur main le met à jour en une à
   deux minutes, sans étape de compilation.
   Quand css/easyroute.css ou un fichier js/ change, changez aussi son numéro ?v=…
   dans index.html (par exemple la date du jour). Les modules js/*.js (sauf
   qrcode.js) partagent un seul numéro : celui de js/main.js, repris pour chaque
   module dans l'import map d'index.html.

2. Les liens courts
   Le dossier worker/ contient le service Cloudflare (Worker + base D1) qui range
   les fiches partagées. Voir la section « Liens courts » du README.

3. Sur l'iPhone
   Ouvrez https://easyroute.cloud dans Safari > Partager > « Sur l'écran d'accueil ».

4. Police de l'étiquette (facultatif)
   Barlow par défaut. Dans l'outil, « Charger une police » accepte un fichier
   .ttf / .otf / .woff2, mémorisé sur l'appareil. Ne mettez pas de police
   commerciale dans le dépôt public.

Tout le reste est décrit dans README.md.
